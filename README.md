# Saudi Trip Checklist (Men)

A single-file, offline-capable **men's** packing checklist for a leisure + business + Umrah trip.

## Features

- **Bag plan**: 30 kg check-in · 7 kg hand carry · 3 kg personal item
- **Men's wardrobe coach**: shirts, trousers, thobe/kurta, shoes — no abaya/headscarf items
- **Bag badges** on every item (check-in, hand carry, personal, wear on plane)
- Collapsible categories with per-section progress
- Filters: To pack / All / Done
- Custom items per category (persisted)
- Dark mode · print-friendly

## Usage

Open `index.html` directly in a browser (works offline from the filesystem).

## Deploy

Static site — publish the repo root to any static host such as Netlify.
